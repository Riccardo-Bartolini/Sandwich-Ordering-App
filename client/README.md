# Sandwich Ordering App — client

React interface for the [Sandwich Ordering App](../README.md), built with Vite, React Bootstrap and React Router.

## Development

From this directory:

```bash
npm ci
npm run dev
```

Start the Express API separately from `../server/` with `node index.mjs`. The development interface uses `http://localhost:5173` and the API uses `http://localhost:3001`.

## Available checks

```bash
npm run build
npm run lint
```

For the application architecture, demo data and security limitations, see the [main README](../README.md).
